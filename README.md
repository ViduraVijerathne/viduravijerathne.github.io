# Vidura's Developer Portfolio (v3)

A high-performance, GSAP-powered scrollytelling portfolio designed for maximum visual impact, utilizing a dark "Apple-style" glassmorphic aesthetic.

## Tech Stack
- **HTML5 & CSS3:** Semantic markup and modern CSS properties (Custom Properties, Grid, Flexbox, backdrop-filter for glassmorphism).
- **Vanilla JavaScript:** Zero framework overhead for lightning-fast parsing.
- **GSAP 3 (GreenSock):** Advanced timeline animations.
- **ScrollTrigger:** For pinned sections and complex scrub animations (Scrollytelling).

## Project Structure
- `index.html`: The main single-page application structure.
- `styles.css`: All CSS styling, carefully scoped and optimized.
- `script.js`: DOM manipulation, intersection observers, and GSAP timeline logic.
- `images/`: High-resolution, AI-generated custom 3D imagery and UI assets.

## Deployment Instructions

This is a **pure static site**, meaning it requires zero build steps or build tools (like Webpack or Vite). 

To deploy to production instantly, you can use any of the following platforms for free:

### 1. Netlify
1. Log in to [Netlify](https://app.netlify.com/).
2. Drag and drop this entire folder into the "Sites" tab, or connect your GitHub repository.
3. Your site will be live instantly.

### 2. Vercel
1. Log in to [Vercel](https://vercel.com/).
2. Create a new Project and import your GitHub repository.
3. No Framework Preset is needed (leave as "Other" or default).
4. Click Deploy.

### 3. GitHub Pages
1. Push this folder to a new GitHub repository (e.g., `vidura-portfolio`).
2. Go to Repository Settings -> Pages.
3. Under "Build and deployment", set the source to `Deploy from a branch`.
4. Select the `main` branch and `/root` folder, then save.
5. Your site will be available at `https://<your-username>.github.io/<repo-name>`.
